集中スポットライト (Concentration Spotlight)

授業やプレゼンテーションで、聞き手の視線を一点に集中させるための「視線誘導（黒板カーテン）」Webアプリです。
プロジェクターで投影した資料の特定部分だけを見せたり、クイズ形式で徐々に情報を公開したりするのに最適です。

✨ 特徴

3つのスポットライト形状:

円形: 特定の単語や図を強調するのに最適。

四角形: 表や写真のブロックを示すのに便利。

スリット（行読み）: 文章を一行ずつ読ませる際に強力な機能です。

黒板/ホワイトボードモード: 画面全体を黒、または白に切り替え可能。

背景画像読み込み: 教科書やプリントの画像を背景に設定し、その上からスポットライトを操作できます。

調整機能: スポットライトのサイズや、カーテンの透過率（うっすら見せるなど）を自由に変更できます。

🚀 使い方

index.html をWebブラウザ（Chrome, Edge, Safariなど）で開きます。

画面が暗くなり、マウスカーソルの周りだけが明るく表示されます。

操作パネル（右下）を使って設定を変更します：

画像を選択: 背景に教材画像を読み込みます。

形状ボタン: 円・四角・スリットを切り替えます。

サイズ/透過率: スライダーで調整します。

リセット: 初期状態に戻します。

🛠 技術スタック

HTML5 (Canvas API)

JavaScript (Vanilla JS - ライブラリ依存なし)

Tailwind CSS (CDN経由で読み込み)

Font Awesome (アイコン用)

📦 インストール

特別なインストールは不要です。index.html ファイルをダウンロードし、ブラウザにドラッグ＆ドロップするだけで動作します。
インターネット接続があれば、CSSやアイコンフォントが正しく読み込まれます。

📱 モバイル対応

タッチ操作に対応しています。タブレットやスマートフォンでも、指でスポットライトを動かすことができます。
